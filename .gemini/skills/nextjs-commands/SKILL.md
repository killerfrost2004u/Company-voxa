# Next.js Commands

Use these instructions to manage the Next.js application:

- **Development Server:** Run `npm run dev` to start the development server on `localhost:3000`.
- **Production Build:** Run `npm run build` to build the application for production.
- **Start Production Server:** Run `npm run start` after a build.
- **Linting:** Run `npm run lint` to check for ESLint errors.
